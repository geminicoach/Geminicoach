# Functional Anatomy for Coaches — image prompts (for ChatGPT)

These are OPTIONAL hero / cover images. The labeled teaching diagrams in the chapters are hand-coded SVG and stay as-is (GPT garbles text and invents anatomy, so it should not make the teaching diagrams). These images are decorative banners that make the course feel premium.

## How to use
1. Paste a prompt below into ChatGPT and ask for a **wide / landscape** image.
2. **No text in the image** — every prompt forbids letters, labels, and arrows on purpose.
3. **Eyeball the anatomy** — AI illustration is not medically exact. Regenerate if a muscle looks clearly wrong (look hardest at hero-ch2 and hero-ch5).
4. Download and **save with the exact filename** shown, into this folder (`courses-standalone/functional-anatomy/`).
5. Tell Claude which ones you added and they get wired into the matching chapter (cover -> home hero; hero-chN -> top of chapter N).
6. Keep the style line identical across all of them (it is baked into each prompt) so the set looks cohesive.

Target: wide landscape (ask ChatGPT for landscape; 1536 x 1024 is ideal). Cover uses a navy background; all chapter heroes use a soft cream background to blend with the reading pages.
