Chapter 2 : Memory, Precision, and the Handoff

Trading speed for specificity: billions of receptors, one match per cell, and a memory that lasts for years.

Innate vs Adaptive, Side by Side

ReceptorsInnate: a few hundred, fixed at birth. Adaptive: billions, assembled per cell by V(D)J recombination.
SpeedInnate: minutes to hours. Adaptive: days for a first response.
SpecificityInnate: recognizes broad microbial categories. Adaptive: recognizes one precise epitope.
MemoryInnate: none. Adaptive: long-lived memory cells enable a faster, stronger second response.

The Two Lymphocyte Lineages

  • T cell : matures in the thymus; T cell receptor (TCR) reads peptide displayed on MHC (MHC restriction).
  • B cell : matures in the bone marrow; B cell receptor (BCR) is a membrane antibody that binds free antigen directly.
  • Both circulate through blood and lymph, waiting in secondary lymphoid organs (lymph nodes, spleen) to meet antigen.

Key Terms

  • Antigen : any molecule an adaptive receptor can bind.
  • Epitope : the small patch of antigen a receptor actually contacts.
  • Antibody : the Y-shaped molecule secreted by activated B cells.
  • MHC : the surface molecule that displays peptide for a T cell to inspect.

Diversity and Selection

  • V(D)J recombination : assembles receptor genes from gene-segment libraries, generating over 1011 possible receptors.
  • Clonal selection : antigen selects the rare pre-existing lymphocyte that already fits it, then that clone expands.
  • Immunological memory : long-lived memory cells left behind after a response make the next encounter faster and stronger.
  • Vaccination : deliberately triggers clonal selection and memory using a harmless antigen.

The Innate-to-Adaptive Handoff

  • Dendritic cells capture antigen at the site of infection.
  • They travel to the nearest lymph node carrying that antigen.
  • There they present it to naive T cells, triggering clonal selection.
  • This is why lymph nodes swell near an active infection.
Where education ends   This builds understanding of how adaptive defense and memory work, not a license to diagnose or treat. Difficulty breathing, facial or throat swelling, or unusually severe or prolonged illness are signs that warrant evaluation by a qualified clinician. Work within your role, whatever it is.
